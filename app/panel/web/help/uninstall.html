怎么卸载

这个工具是绿色版：不写注册表、不装系统服务、不加开机启动、不改环境变量。 卸载只有两件事——停掉进程、删掉文件夹；外加一条可能存在的防火墙规则。

最快：双击根目录的 卸载.bat

  1. 选 1：停止服务、清理防火墙规则，文件夹保留（排查/重装时用）。
  2. 选 2：停止并删除整个文件夹（不可恢复）。

手动：三步

  1. 面板 →「运行管理」→「停止」，然后关掉面板网页/窗口。
  2. 把 xiaozhi-oneclick 整个文件夹删掉。
  3. 删不掉时打开任务管理器，结束路径在本文件夹下的 python.exe，再删。

防火墙规则

如果点过「连不上？放行防火墙」，会有一条名为 XiaozhiServer 的入站规则。 卸载.bat 会尝试删除；也可在「Windows Defender 防火墙 → 高级设置 → 入站规则」里删掉， 或管理员 PowerShell：netsh advfirewall firewall delete rule name="XiaozhiServer"

✓ 想保留配置重装：把 data 文件夹复制出来（settings.json / memory.db / 日志）， 新包解压后放回去，再跑一次「安装部署」即可，密钥和记忆都在。

不会在 %APPDATA%、Program Files 或计划任务里留下任何东西。
