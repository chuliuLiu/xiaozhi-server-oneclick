怎么拿到千问AI平台 API Key

机器狗的「耳朵」（语音识别）、「嘴」（语音合成）和「脑子」（大模型）都跑在千问AI平台上。开通一次、拿一个 API Key，三样一起用。

全程在网页上操作，不需要安装任何东西。大约 5 分钟。

五步拿到 Key

  1. 打开千问AI平台控制台并登录

    用支付宝或淘宝账号登录阿里云即可。第一次用需要做一次实名认证（个人认证几分钟就好）。

    https://platform.qianwenai.com/home

  2. 开通「千问AI平台」服务

    第一次进入控制台会提示开通，点一下开通（免费）。开通后才能调用语音和大模型接口。

  3. 创建 API Key

    页面左上角 →「API-Keys」→「创建 API Key」。复制 sk- 开头的那一串。

  4. 粘回面板保存

    回到「密钥参数」页，把 Key 粘进输入框，点「保存并测试」。看到「Key 能用」就成功了。

  5. 确认账户里有可用额度

    新账号一般有免费额度；额度用完会提示「余额不足」。在控制台「费用与成本」里充值即可，充多少用多少。

✓ 一个 Key 就够了。语音识别、语音合成、qwen 大模型都认这个 Key，不需要分别申请。

要花多少钱

项目怎么计费体感
语音识别按音频时长很便宜，日常聊天一个月通常几块钱
语音合成按合成字数/时长同上
大模型按输入输出 token用 qwen3.8-flash 这类小模型，成本很低

具体价格和套餐（含 Token Plan）以千问AI平台控制台显示为准，这里不写死数字，免得过期误导你。

! 别买网上的「共享 Key」。那种 Key 随时会被封，而且你的对话会经过别人的账号。自己在官网申请最稳，也更便宜。

常见问题

填了 Key，但试听没有声音展开

按顺序排查：① Key 是否复制完整（sk- 开头，没有空格）；② 千问AI平台是否已开通；③ 账户是否有余额；④ 电脑能否正常上网。面板的「自检」会告诉你卡在哪一步。

Key 会不会泄露展开

Key 只保存在这台电脑的 data\settings.json 里，只有当前 Windows 用户可以读取。面板不会把它上传到任何地方；日志里也会自动打码成 sk-****。

能不能用别家大模型展开

可以。在「密钥参数 → 大脑」里切换成智谱，或者选「自定义」填任何 OpenAI 兼容的地址。语音仍然走百炼。

换电脑了要重新申请吗展开

不用。把 Key 复制到新电脑的面板里就行；同时建议在千问AI平台控制台删掉旧 Key，避免泄露。
