用自己的声音

百炼支持「声音复刻」：上传一小段录音，训练出一个专属音色，机器狗就用这个声音说话。整个过程在网页上完成，大约 10 分钟。

训练需要一点时间，通常几分钟到半小时；期间可以先用预置音色。

六步拿到自己的音色 ID

  1. 打开百炼控制台的「声音复刻」

    登录后左侧菜单找到「音色复刻 / 声音复刻」，选择「CosyVoice 声音复刻」。

  2. 录一段干净的人声

    安静房间，离麦克风 20 厘米左右，正常语速读页面给的示例文本，10~30 秒即可。不要有背景音乐、回声、其他人说话。

  3. 确认授权

    必须是你自己的声音，或已获得本人书面授权。不要复刻他人声音用于对外发布。

  4. 提交训练并等它完成

    页面会显示进度。完成后音色列表里会出现一个很长、以 cosyvoice-v3-flash-bailian- 开头的 ID。

  5. 复制音色 ID

    点复制按钮。注意只要 ID 本身，不要带引号或空格。

  6. 粘回面板并试听

    「密钥参数 → 语音」：语音模型选 CosyVoice v3 flash，把 ID 填进「自定义音色 ID」，点「试听」。听到自己的声音就成功了，再点保存。

✓ 模型要和音色配套。复刻出来的音色只能配 cosyvoice-v3-flash（或 v3 系列）使用；选 v2 会报「音色不可用」。

常见问题

试听报「音色不可用 / voice not found」展开

九成是模型和音色不配套：v3 复刻的音色要选 v3 flash。也可能是 ID 复制漏了几位，或者训练还没完成。

预置音色为什么有的能用、有的报错展开

不同模型有各自的音色表，不能混用。面板会按模型切换音色列表；如果某个音色在你的账号上不可用，换一个或换 v3 flash 即可。

复刻要多少钱展开

声音复刻本身按百炼的计费规则收费（有免费额度时先用额度），合成按字数/时长计费。具体价格以控制台为准。

录坏了想重来展开

直接再提交一次即可，旧的音色可以留着，也可以在控制台删掉。
