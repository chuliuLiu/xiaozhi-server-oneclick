第一次打开有安全提示？

这是 Windows 对所有「从网上下载的压缩包」的标准提示，不是检测到了病毒。看懂原因、按下面做一次就好。

为什么会出现

通过浏览器、微信、网盘下载的文件，Windows 会给它打一个「来自 Internet」的标记（Mark of the Web）。解压后，里面的 python.exe、ffmpeg.exe、.bat 都带着这个标记，所以第一次运行时 Windows 会问一句：

  • 「打开这些文件可能会对你的计算机有害」
  • 「Windows 已保护你的电脑」（SmartScreen）
  • 「无法验证发布者」

这些程序没有买商业代码签名证书（一年几千块，个人小工具一般都不买），所以显示「未知发布者」是正常的。

✓ 最省事的做法：先解锁压缩包，再解压。这样解压出来的所有文件都不会再弹提示。

方法一：解压前解除锁定（推荐）

  1. 在压缩包上点右键 →「属性」。
  2. 在「常规」最下面，勾上「解除锁定 / Unblock」，点「确定」。
  3. 再解压。之后运行 启动面板.bat 不会再提示。

方法二：已经解压了

对整个文件夹解锁一次（在文件夹里打开 PowerShell 也可以）：

Get-ChildItem -Recurse | Unblock-File

或者对单个文件：右键 启动面板.bat → 属性 → 解除锁定。

方法三：SmartScreen 拦了 bat

点提示里的「更多信息」→「仍要运行」。只需要点这一次。

! 杀毒软件报 python.exe / ffmpeg.exe 可疑怎么办？便携 Python 和 ffmpeg 是开源软件，很多杀软对「绿色版 exe」比较敏感。确认来源是你下载的这个包后，可以把整个文件夹加入杀软排除项，或选择「允许」。不要从别人的网盘随便下一个同名包。

如何确认这个包没被改过

发布页会给出压缩包的 SHA-256。在 PowerShell 里运行：

Get-FileHash .\xiaozhi-oneclick-0.2.0.zip -Algorithm SHA256

和发布页对比，一致就说明文件完整、没被替换。

本工具不联网校验、不上传任何信息；密钥只存在本机。
