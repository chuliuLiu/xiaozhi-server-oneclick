小智本地服务 · 一键版
=====================

1. 把整个文件夹放在「纯英文、无空格」的路径下，例如 D:\xiaozhi
2. 双击「🚀启动面板.bat」，浏览器会自动打开控制面板
3. 按页面提示：环境检查 → 填千问AI平台 API Key → 选音色试听 → 启动服务
4. 把「运行管理」里的 OTA 地址填到机器狗的配网页面

不需要安装 Python，不需要 pip，不需要改环境变量。
密钥只保存在本机 data\settings.json，不会上传。

第一次打开如果 Windows 提示「可能有害 / 无法验证发布者」：
  右键压缩包 → 属性 → 勾选「解除锁定」→ 确定，然后再解压。
  详细说明见面板左下角「第一次打开有安全提示？」。

想用自己的声音：面板 →「密钥参数」→ 音色下方「声音复刻教程」。

常见问题：面板左下角「常见问题」；狗说「模型还没开通」就是模型名过期，去「密钥参数」点「获取列表」选 deepseek-v4.1-flash-1017。

遇到问题先点「运行自检」；要发给别人排查，打包 data\logs 里的日志即可。

关闭面板：面板左下角「退出面板」；只关浏览器标签不等于关面板（面板还在后台跑）。
双击 bat 重复打开不会起第二个面板，只会把已经在跑的那个页面调出来。
卸载：双击根目录「卸载.bat」。本程序不写注册表、不装服务、不加开机启动。
